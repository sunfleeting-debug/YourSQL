# 工作台设计记录

## 产品形态

面向高频使用的数据库 IDE：连接栏、可折叠数据库对象栏、可并行保留多个查询标签的 SQL 编辑器与结果区。每个查询标签独立保存 SQL 文本、光标/选区、执行结果、批次历史与错误定位；查询历史并入结果区页签，不再占用第二个侧栏。存储是顶部模式切换进入的独立只读工作区，不与编辑器、结果挤在同一列。前端用 React / Vite / CodeMirror，后端沿用标准库 HTTP 与既有数据库对象。

## 视觉基准

- 白色主工作面；冷灰侧栏 `#f5f7fa`，分隔线 `#e3e7ec`，正文 `#202938`，辅助文字 `#718096`，青色主操作 `#087f78`。
- 控件 12–13px，编辑器 14px 等宽；间距 8/12/16px，圆角 4px，图标统一 1.8px 描边 SVG。
- 栏宽可折叠，编辑器与结果上下分区，避免嵌套卡片。

设计概念由内置 ImageGen 生成为本机产物（路径不入仓），只作布局参考，不作运行时 UI 或数据来源。概念里的示例表、存储过程、日期字段与统计都不代表界面固定数据；实现只展示真实目录、真实执行结果与支持说明。登录、权限弹窗、结果导出、只读存储检查、状态轮询是验收所需的补充状态。

## 组件划分

`AppShell`、`SchemaBrowser`、`SqlEditor`、`ResultPanel`、`PipelinePanel`、`StageCanvas`、`StoragePanel`、`PageGrid`，外加统一 API 客户端、类型模型与 SQL 分隔辅助函数。

- **对象栏**：按“用户表 / 用户视图 / 系统视图”分组，系统视图只对 admin 返回；点用户视图载入定义 SQL，点系统视图载入可执行的公开查询入口，完整定义默认收起为“查询定义”。
- **流水线**：按“编译 / 计划 / 执行观测”组织为顶部阶段条，Token 用逐行表格，AST 用结构树，逻辑计划与优化计划用只读 `PlanNode.children` 的算子图，`properties` 在选中算子详情里展示。算子图支持方向箭头、节点选择、属性检查与缩放，窄屏退化为上下布局。优化器按统计信息与索引最左前缀选 SeqScan/IndexScan，优化后的节点由 SQL evaluator 消费，物理阶段明确标注仍复用该 PlanNode。
- **页面画布**：按真实字节边界生成固定小方格，外层页头、`MSP2` 页内头、槽目录、空闲片段与页尾记录区分别着色；每格宽度固定为一个槽目录项（当前 6 B），不足整格的边界用比例分段格表示，位置索引画在网格外框，视口支持横向/纵向平移。点击多格区域按“区域完整 Hex/ASCII → 具体格 → 区域汇总”循环，单格直接看详情。
- **块点击语义**：点其它页时一次点击直接切换并加载新页；点当前页保持已选中的块与右栏不变。右栏只由关闭按钮或 Esc 收起。（旧实现切换页时只清空选中态，表现为“第一次点击折叠、第二次才切换”。）
- **常驻右栏**：两栏列宽只由 `has-rail` 决定，开关块详情不改地图列数与滚动位置；未选中块时只给一行占位提示。（旧实现用依赖块选中态的 `has-detail` 切列，一点方块地图就横向重排。）`PageGrid` 的重置副作用只依赖页号，回调经 ref 转发，页面详情刷新（手动刷新、SQL 完成后的自动刷新）不会静默关掉抽屉。
- **数据来源**：后端返回真实完整单页字节与 `free_regions`，前端不生成计划或存储数据；目录页 payload 按权限遮蔽。新 HEAP 记录从页尾向前分配，插入优先复用空闲片段并保持其它记录的物理 offset，只有找不到连续空间时才压缩页内记录。项目内数据库统一为 30 B 对齐外层页头。

## 存储检查刷新策略

- **全量加载**：首次进入页面页签或用户点“地图”时执行，按 `fields=map` 以 500 页/批拉取，只取画地图必需的页头（类型、页大小、空闲、槽数），不算逐页目录归属、不重算索引绑定表 —— 4860 页演示库从 25–45 s 降到约 1.8 s。表名/索引名在选中页时由 `/api/storage/pages/{page_id}` 按需补齐。
- **增量合并**：BufferPool 为页内容与页生命周期维护有界变更游标，SQL 完成或用户刷新存储页签时用 `/api/storage/changes` 拉变更页头并在前端合并；变更日志超出保留范围时自动退回全量加载。
- **局部刷新**：选中页走 `/api/storage/pages/{page_id}`，缓存统计走 `/api/storage/cache`，索引目录走独立接口。`buffer_pool.eviction_order` 返回可淘汰页号的升序队列，首项最先淘汰，Pin 中的页不进入队列。
- **不做周期性自动刷新**：避免刷新时重建视图导致选中状态与滚动位置丢失，只保留 SQL 完成后的轻量同步与各页签/当前页的手动刷新。
- **策略切换**：`POST /api/storage/cache/policy` 受 `SECURITY` 权限保护，可在不清空现有缓存帧的前提下切换 LRU/FIFO，从下一次淘汰开始生效。
